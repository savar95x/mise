# Mise

A private journal for what you watch: films and shows, one place.

- **Diary**: every watch, by date. Rewatching adds a new entry, so what you thought the first time stays.
- **Talk about it**: tap the mic after the credits and just talk. The memo is kept, and on Android 13+ your words
  are written into Thoughts as you speak (on-device when the phone supports it).
- **State of mind**, a **verdict** (All-time, Great in its lane, Good, Fine, Not for me) and optional **scores** for
  story, direction, performances, sound & score, visuals and engagement. No single number.
- **How you watched**: 4K, HDR, surround, dark room, cinema…
- **Watchlist**: logging a title takes it off.
- **Story card**: a clean Instagram story ("Watched · Interstellar · Film #47 of 2026"). Your review isn't on it,
  only a line if you write one.
- **Sync** (optional) through your own free Supabase project, text only. **Backup** to a zip with every voice memo.
- Theme, pure black, any Google Font, six app icons.

Search uses [TMDB](https://www.themoviedb.org): add a free API token in Settings. This product uses the TMDB API
but is not endorsed or certified by TMDB.

Install the APK from [Releases](../../releases). Mise updates itself from there.
